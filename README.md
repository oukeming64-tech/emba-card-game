# 任何人都能看懂并上手的 EMBA 课程！

一款以 EMBA 经历、商业教育与个人观察为素材的原创 2D 卡牌 Roguelike。

项目借鉴成熟卡牌爬塔游戏的循环结构，但角色、文本、世界、界面、代码、美术与音频均按本项目独立制作和管理。

## 安装

1. 从 Release 页面下载 DMG。
2. 打开 DMG，将游戏拖入 `Applications`；已有旧版时替换应用。
3. 当前版本使用 ad-hoc 签名，尚未进行 Apple Developer ID 签名或公证。如果 macOS 首次阻止打开，请在 Finder 的“应用程序”中右键游戏，选择“打开”，再确认一次。

应用标识与存档位置沿用旧版。本次更新不改变玩法规则或存档格式。

## 这款游戏从哪里来

游戏与论文《从创造到收割：商业教育价值体系的异化与泡沫的文化逻辑》来自同一段 EMBA 经历。论文讨论创造、流通与收割；游戏则把那些难以只靠文字说明的选择与代价，放进了一座可以亲自进入的塔里。
